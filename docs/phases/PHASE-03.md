# Phase 3 — 부동산 유동화 + 절세 시나리오

> **상태:** 예정

> **작성일:** 2026-06-06  
> **최종 갱신:** 2026-06-06

## 1. 목표

부동산 매각·거주지 이동·양도세·주택연금 시나리오를 시뮬레이션하여 **한국형 노후 준비 킬러 기능**을 제공한다.

---

## 2. 범위

### 2.1 포함 (In Scope)

- [ ] 거주지 이동 시뮬레이터 (상·하급지, 2주택 상태)
- [ ] 양도소득세 계산기 (1세대 1주택 비과세 요건)
- [ ] 부부 공동명의 종부세/양도세 비교
- [ ] 주택연금 월 수령액 시뮬레이션
- [ ] 매각 대금 재투자(IRP/주식) 현금흐름 추적
- [ ] 시나리오 A/B 비교 차트

### 2.2 제외 (Out of Scope)

- 목돈 지출 타임라인 → Phase 4
- PDF 리포트 → Phase 4
