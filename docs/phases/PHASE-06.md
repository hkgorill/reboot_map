# Phase 6 — 복수 부동산 + 주거용/비주거용 보유세

> **상태:** ✅ 개발 완료 (실기기 검증 대기)  
> **버전:** `1.5.1-phase6`  
> **선행:** [PHASE-05.1](PHASE-05.1.md)

---

## 1. 목표

부동산 자산을 **복수 건** 입력하고, **주거용·비주거용**을 구분해 보유세(재산세·종부세)를 합산·분리 계산한다.

---

## 2. 구현 범위 (완료)

| ID | 항목 | 내용 |
|----|------|------|
| P6-01 | 부동산 추가·삭제 | 최대 **10건**, `real_estate_1` … `real_estate_10` |
| P6-02 | 유형 | `RealEstateCategory` — **주거용** / **비주거용** (세금 체계 명칭) |

| P6-04 | 종부세 | Σ순자산, 6억 공제·0.6% |

| P6-06 | 월표·PDF·가이드 | 수입·세금 breakdown, 보유세는 **월 세금에 통합** 표시 |

### UX 보완 (1.5.1)

- 신규 부동산 기본 유형 **주거용**
- `ManWonInputField` — 포커스 중 숫자만 표시 (중간 입력 시 커서 점프 방지)
- 월표: **월 수입** 탭 → 소득 항목별 / **월 세금** 탭 → 소득세·건보·재산세·종부세
- 총자산 안내 문구 — 마일스톤 연령(60·65·70·80세) **하단 1회**

---

## 3. 도메인

```kotlin
enum class RealEstateCategory {
    PRIMARY_RESIDENCE,   // 주거용
    NON_RESIDENTIAL,     // 비주거용
}
```

```
재산세 = Σ (각 순자산 × 유형별 세율)
종부세 = max(0, Σ순자산 − 6억) × 0.6%
```

`AnnualIncomeBreakdown` — 연금·소득·매각 등 수입 세목 (월표 탭용).
