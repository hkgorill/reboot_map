# Phase 9 — 대시보드 UX·자산운용 리포트·부동산 타이밍 컨설팅

> **상태:** ✅ 개발 완료 (실기기 검증 대기)  
> **버전:** `1.8.0-phase9`  
> **선행:** [PHASE-08](PHASE-08.md)  
> **작성일:** 2026-06-08

---

## 1. 목표

1. 대시보드 입력·결과를 **그룹 접기/펼치기**로 정리하고, 접힌 상태에서도 요약이 보이게 한다.
2. **자산운용 총평**·이벤트 기반 월표·**PDF 자산운용 리포트**로 결과 가독성을 높인다.
3. 주거 로드맵 UI를 **부동산 최적 보유 타이밍 컨설팅**으로 대체하고, 취득·매각 연도·간이 세법을 포트폴리오 단위로 반영한다.

## 3. 대시보드 그룹 (기본 펼침)

| 그룹 | 기본 | 요약 예 |
|------|------|---------|
| 시뮬레이션 결과 | 펼침 | 점수·고갈·최종 자산 |
| 생활·주거 계획 | 접힘 | 목돈 N건 |
| 기본 정보 | 접힘 (온보딩 직후 펼침) | 나이·생활비·세금 가정 |
| 부동산 | 접힘 | N건·2주택 겹침·컨설팅 |
| 연금·수입·투자 | 접힘 | 입력 N/M |
| 부채 | 접힘 | 잔액·월 상환 |

---

## 4. 부동산 세법 (간이)

| 구분 | 반영 |
|------|------|
| 취득세 | 취득 연도, 다주택 시 가중 |
| 중개보수 | 매수·매도 각 약 0.5% |
| 양도세 | 1주택 비과세, 다주택 +10%, 일시적 1가구2주택 |
| 재산세·종부세 | 보유 중 매년 (`PropertyHoldingTaxEngine`) |
