## 1. 목표

자녀 결혼·유학·대학 등 **생애주기 대형 지출**을 타임라인에 배치하고, 자산 매칭·PDF 컨설팅 리포트로 노후 방어선을 완성한다.

---

## 2. 범위

### 2.1 포함 (In Scope)

- [x] 목돈 지출 타임라인 (지출 일정 요약 + 연도 ◀▶ 조정)
- [x] 자산 매칭 알고리즘 (지출 항목별 추천 자산)
- [x] PDF 컨설팅 리포트 생성·공유
- [x] 시뮬레이션 결과 + 가이드라인 통합 리포트

### 2.2 제외 (Out of Scope)

- 드래그 앤 드롭 마일스톤 재배치 (후속 개선)
- 별도 «자산 매칭» 메뉴 (지출 항목 내 인라인 표시)
- 서버 연동·클라우드 백업 · 마이데이터 연동
