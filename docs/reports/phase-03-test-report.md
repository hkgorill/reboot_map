## 4. 자동 재계산 구조 (참고)

```
입력 변경 → SimulationViewModel.calculate()
         → CashFlowEngine.project() → CashFlowProjection
         → ResultSummaryCard + CashFlowChartCard (동일 projection 공유)
```

- 미입력 자산은 `hasValue()` 기준으로 시뮬레이션에서 제외
- 온보딩 3항목은 항상 반영 (자산 없어도 생활비 기반 시뮬레이션 수행)
- 저장(DataStore)만 300ms debounce, 계산·UI 갱신은 입력 직후 수행
